# 📋 智能剪贴板管理器

一个功能强大的 Windows 剪贴板历史记录管理工具，支持文本内容的自动捕获、分类、搜索和快速粘贴。

## ✨ 核心功能

### 🔍 剪贴板监听与捕获
- ✅ 后台自动监听剪贴板变化
- ✅ 智能去重机制（相同内容不重复记录）
- ✅ 自动更新访问时间

### 📂 历史记录管理
- ✅ 时间轴视图，置顶功能优先显示
- ✅ 内容预览，支持长文本截断
- ✅ 批量操作（删除、复制）
- ✅ SQLite 本地持久化存储

### 🤖 智能分类与标签
- ✅ 自动识别内容类型：代码、链接、邮箱、命令行、普通文本
- ✅ 基于关键词自动提取标签
- ✅ 类型图标直观展示

### 🔎 搜索与检索
- ✅ 全文实时搜索
- ✅ 按类型过滤
- ✅ 搜索结果高亮显示

### ⌨️ 快捷操作与粘贴
- ✅ 全局热键 `Ctrl+Shift+V` 呼出快速选择面板
- ✅ 双击或回车快速粘贴
- ✅ 选中后自动复制到剪贴板
- ✅ 支持自动模拟 `Ctrl+V` 粘贴

### ⚙️ 配置管理
- ✅ 可配置最大历史记录数
- ✅ 热键自定义
- ✅ 自动清理策略

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行程序
```bash
python main.py
```

### 3. 使用方法
- **正常使用**：程序启动后会自动在后台监听剪贴板，复制的内容会自动保存
- **快速粘贴**：按下 `Ctrl+Shift+V` 呼出快速选择面板，输入关键词搜索，上下箭头选择，回车粘贴
- **主界面**：查看完整历史记录，支持右键菜单操作（复制、置顶、删除）
- **类型过滤**：在主界面顶部选择类型进行过滤
- **搜索**：在搜索框输入关键词实时搜索

## 🎯 技术特性

- **跨平台**：基于 Python 和 Tkinter，支持 Windows/macOS/Linux
- **轻量级**：资源占用低，后台静默运行
- **隐私安全**：所有数据本地存储，不上传云端
- **可扩展**：模块化设计，易于添加新功能

## 📌 快捷键说明

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+V` | 呼出快速粘贴面板 |
| `Enter` | 选中并粘贴 |
| `ESC` | 关闭快速面板 |
| `↑/↓` | 上下选择条目 |
| 双击鼠标 | 复制并粘贴 |

## ⚠️ 注意事项

1. 首次运行需要安装依赖包
2. 全局热键可能与其他软件冲突，可在 config.json 中修改
3. 程序关闭后会继续在后台运行，如需完全退出请在任务管理器中结束进程
4. 数据库文件会自动增长，定期清理旧记录可减少磁盘占用

## 🔧 配置说明

config.json 中的可配置项：
```json
{
  "max_history": 1000,        // 最大历史记录数
  "auto_clean_days": 30,      // 自动清理天数
  "hotkey": "ctrl+shift+v",   // 全局热键
  "theme": "light",           // 界面主题
  "show_preview": true,       // 显示预览
  "auto_paste": true,         // 选中后自动粘贴
  "privacy_mode": false       // 隐私模式
}
```
